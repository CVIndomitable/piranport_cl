## 安装

1. 安装 **NeoForge 21.1.x**（对应 Minecraft 1.21.1）
2. 将 `piranport-1.1.58-dev.jar` 放入 `mods/` 文件夹
3. （可选）JEI 查看厨房/弹药配方；Patchouli 阅读航行手册（未安装时手册物品会提示）
4. 启动游戏

**附属模组**（独立仓库，单向依赖本模组，可不装）：
- `piranport-coffee` — 咖啡与饮品扩展
- `piranport-resources` — 资源树扩展

## 快速上手

```
1. 挖矾土矿 → 熔炼铝锭，收集燃料
2. 合成舰装核心，放入副手
3. 武器/弹药放快捷栏，核心自动计入负重
4. Shift+右键核心 → 变身
5. 主手持武器/飞机 → 右键发射/放飞
6. 鼠标中键锁定目标，H 键开启自动模式（自动升空/防空/近防）
7. 侦察机放飞后自动切换视角，WASD 操控，V 键退出
```

## 按键一览

| 按键 | 功能 |
|------|------|
| `Shift + 右键`（副手核心） | 变身启动/解除 |
| `右键` | 主手武器发射 / 飞机放飞 |
| `鼠标中键` | 火控选择目标：不蹲=加选（上限4）；蹲下+有目标=单选；蹲下+无目标=清空 |
| `H` | 自动模式总开关（战斗机自动升空 / 防空导弹 / 自动近防炮） |
| `R` | 装填：火炮读条、鱼雷再装填、飞机补油+挂载、防空导弹补给 |
| `Tab`（按住） | 火炮弹药轮盘 |
| `V` | 退出侦察机视角 |

## 舰装核心参数

| 舰型 | 血量加成 | 负重上限 | 武器槽 | 弹药槽 | 强化槽 | 燃料 | 满载速 | 空载速 | 护甲 |
|------|---------|---------|--------|--------|--------|------|--------|--------|------|
| 小型 | +20 | 40 | 4 | 4 | 2 | 10 | 1.15 | 1.4 | 8 |
| 中型 | +30 | 64 | 5 | 4 | 3 | 20 | 1.0 | 1.2 | 12 |
| 大型 | +40 | 112 | 6 | 4 | 4 | 30 | 0.85 | 1.0 | 16 |
| 潜艇 | +12 | 32 | 4 | 4 | 2 | 10 | 0.7 | 0.8 | 4 |

- **负重** = 快捷栏武器 + 核心内装甲/强化件 + 在飞舰载机（放飞/回收不改变总负重）
- **移速**在空载～满载之间线性过渡，引擎强化件提供额外加速
- **超载惩罚**：>115% 挖掘疲劳；>130% 虚弱；>150% 缓慢
- 核心槽位固定副手；改装器可微调武器/强化槽数量

## 飞机机种

| 机种 | 负重参考 | 攻击方式 |
|------|---------|---------|
| 战斗机 | 12～14 | 悬停射击；火箭战斗机发射火箭弹 |
| 俯冲轰炸机 | 16～24 | 俯冲接触投弹 |
| 水平轰炸机 | 22 | 绕背进入 → 前抛航弹（继承载机速度）→ 拉起重新瞄准 |
| 鱼雷轰炸机 | 16 | 低飞投雷 |
| 反潜机 | 14 | 低飞投深弹（声呐标记水下目标） |
| 侦察机 | 8 | 放飞切视角 WASD 操控，兼任空中声呐/雷达平台 |

- 机型全部由 `data/piranport/aircraft/*.json` 数据驱动，攻击方式由 `attack_profile` 决定
- 燃油耗尽或超时自动返航母舰；深海航母自主机打完返航回收甲板槽位
- 放飞时编组模式固定 FOCUS（全组集火锁定列表首目标）；无锁定时自动索敌敌对生物

## 火控与高亮

| 操作 | 效果 |
|------|------|
| 中键对准目标 | 追加锁定（最多4个，范围走终端参数） |
| 蹲下+中键对准目标 | 单选（替换为当前准星目标） |
| 蹲下+中键（无目标） | 清空全部锁定 |
| 无锁定 | 自动索敌最近敌对生物 |

- 瞄准点统一取目标**眼睛高度**（例外：VT近炸取几何中心、鱼雷拦截取发射高度）
- HUD 预瞄圈 + 炮弹/航弹预测落点标记（圆环随剩余散布收缩）
- 火控雷达（强化件）让弹道中段追踪目标，分三级追踪范围
- 高亮优先级：原版发光 > 火控红框 > 声呐黄框（声呐标记所有水生生物）

| 要素 | 说明 |

| 记录点 | 续关从记录点继续 |

## 深海NPC

29 份数据驱动配置（`data/piranport/npc/deep_ocean/`）：

- **基础舰种 12**：补给酱、驱逐、防空驱逐、轻巡、重巡、战巡、战列、轻母、航母、潜艇、雷巡、运输
- **高级变体 10**：各舰种的 high_ 版本
- **命名旗舰 6**：Boss、旗舰、装甲航母、深海信浓、深海大凤、深海瑞鹤
- **训练靶 1**：金猫猫（活动关）

**舰队集群 AI**：4～6 船一组、四种队形、共享首个发现目标；潜艇交战下潜隐身；鱼雷舰持续瞄准→发射准备→齐射；高级轻巡以上配备防空（火炮近炸/导弹制导）。

## 调试终端与命令

**调试终端**（手持右键打开，单机房主/联机 OP）：
- 运行时调整全系统手感参数（火炮/弹药/鱼雷/导弹/飞机/深海/副本等），即时生效并持久化
- 参数 CSV 导入/导出（服务器 `config/piranport/exports/`）
- 调试模式开关、测试模式、命中显示、状态快照

**`/ppd` 调试命令**（OP）：

| 命令 | 说明 |
|------|------|
| `/ppd spawn_ruin <type>` | 强制生成遗迹 |
| `/ppd spawn_abyssal <type> [count]` | 刷出深海NPC |
| `/ppd spawn_ship_girl <variant>` | 刷出舰娘 |
| `/ppd target_fire` / `target_b25` | 生成测试靶 |
| `/ppd model_debug <model> [variant]` | 模型调试 |
| `/ppd acceptance_kit <type>` | 验收工具包 |
| `/ppd locate_ruin <type>` | 定位最近遗迹 |
| `/ppd tps` | TPS 显示 |

## 配置

`config/piranport-common.toml` 仅保留两项：

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `combat.explosionBlockDamage` | `true` | 炮弹/鱼雷爆炸是否破坏方块 |
| `gameMode.giveGuidebookOnFirstJoin` | `true` | 首次进世界赠送航行手册 |

其余手感/平衡参数（原各 TOML 配置）已全部迁移至**调试终端**统一管理。
